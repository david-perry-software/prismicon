=== README registration recipe (PR #13 @ 74363c2)

README.md "## Adding a variant (maintainers)" step 2 reads:
  "Register it in src/variants/index.js by adding it to the BUILT_IN_VARIANTS
   registry and re-exporting it from src/index.js."

Re-exporting the descriptor from src/index.js is wrong: src/index.js re-exports
only the variant machinery (defineVariant, listVariants, validateVariant, ...),
never individual descriptors, and check-variants' exports gate pins the exact
18-name export list — a maintainer following the recipe literally would fail
`npm run check:variants` with "src/index.js export list drifted".

=== Windows portability (PR #13 @ 74363c2)

scripts/check-variants.mjs checkPack() calls
  spawnSync('npm', ['pack', '--dry-run', '--json'], ...)
On Windows there is no `npm` executable (only npm.cmd / npm.ps1), so spawnSync
fails with ENOENT and the maintainer gate cannot run on Windows.
